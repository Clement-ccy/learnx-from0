# DeepSDF 从零学习

三个 Notebook 均按「Markdown 讲解 → 代码」组织，按以下顺序学习：

| Notebook | 学习内容 | 运行依赖 |
| --- | --- | --- |
| [01 · SDF 基础与单物体拟合](01_SDF基础与单物体拟合.ipynb) | 解析球体 SDF、空间采样、MLP 拟合、截面对比、Marching Cubes 网格提取 | 独立运行 |
| [02 · 多物体 Auto-Decoder](02_多物体Auto-Decoder.ipynb) | 多个椭球体、潜在编码、共享解码器、联合训练与模型保存 | 独立运行，无需第一篇的训练结果 |
| [03 · 新物体潜在编码重建](03_新物体潜在编码重建.ipynb) | 加载解码器、采集目标观测、优化新编码、比较重建前后 | 需要第二篇保存的 `artifacts/auto_decoder.pt` |

每一篇都有自己的导入和初始化，可以使用独立内核。第二篇通过权重文件把训练结果传递给第三篇，不需要跨 Notebook 共享变量。

这是教学用简化实现，不是论文官方实现。椭球体使用近似距离场；新物体实验使用带距离标签的表面附近样本，不能直接代表真实触觉重建。

## 开始运行

```bash
cd deepsdf
uv sync
uv run jupyter lab
```

在 Jupyter 中选择当前环境的 Python 内核，从头顺序运行。实验支持 CPU，但默认训练步数和批量较大，可能耗时；可先在对应单元降低步数和批量，再增加以改善拟合。通用环境说明见[根目录 README](../README.md)。

运行第二篇末尾的保存单元后，再打开第三篇。生成的权重位于本目录的 `artifacts/` 中，不提交到仓库；重新保存会覆盖原权重。Notebook 中保留的已有输出用于阅读，实际结果以重新运行后的输出为准。
