# 05_优化循环 (Optimization Loop)

## 1. 目标
给定一张目标图像 (Ground Truth)，我们要自动调整高斯球的参数，使得渲染结果尽可能接近目标图像。

## 2. 可学习参数 (Learnable Parameters)
每个高斯球都有以下参数需要优化：
- `position`: $(x, y, z)$
- `scale`: $(s_x, s_y, s_z)$
- `rotation`: 四元数或欧拉角
- `opacity`: $\alpha$ (通常经过 Sigmoid 激活限制在 0-1)
- `color`: SH 系数或 RGB (通常经过 Sigmoid 限制在 0-1)

## 3. 损失函数 (Loss Function)
最简单的 Loss 是 L1 Loss（绝对误差）：
$$ Loss = | I_{render} - I_{gt} | $$

更高级的实现会加入 D-SSIM (Structural Similarity) Loss。

## 4. 优化流程
1.  **Forward**: 渲染当前参数下的图像。
2.  **Loss**: 计算渲染图与目标图的差异。
3.  **Backward**: PyTorch 自动计算梯度 $\nabla Loss$。
4.  **Step**: 优化器 (Adam) 更新参数：$\theta = \theta - \eta \cdot \nabla Loss$。

## 5. 坑点：梯度消失与爆炸
- **透明度**: 如果 $\alpha$ 变成 0，梯度就会消失（看不见了怎么优化？）。
- **位置**: 如果高斯球移出了屏幕，梯度也会消失。
- **解决**: 3DGS 有一套复杂的“自适应密度控制”策略（克隆、分裂、修剪），但在本教程的基础版中，我们先只关注参数优化。
