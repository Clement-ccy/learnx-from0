## 1️⃣ 张量 (Tensor) - 数据的容器

### 💡 日常类比
想象你在管理一个图书馆：
- **标量（0维张量）**：一本书的价格 → `29.9`
- **向量（1维张量）**：一排书架上所有书的价格 → `[29.9, 35.0, 42.5]`
- **矩阵（2维张量）**：整个书库的书架排列，每个位置记录书的价格
- **3维张量**：多层楼的图书馆，每层都有书架排列

### 🔢 数学理解
```
标量：      5
向量：      [1, 2, 3, 4]
矩阵：      [[1, 2, 3],
            [4, 5, 6]]
3维张量：   [[[1, 2], [3, 4]],
            [[5, 6], [7, 8]]]
```

### 📊 在Transformer中的应用
- **句子** = 2维张量 `[序列长度, 词向量维度]`
- **批次句子** = 3维张量 `[批次大小, 序列长度, 词向量维度]`

**例子**：处理3个句子，每句最多10个词，每个词用512维向量表示
→ 形状：`[3, 10, 512]`

## 2️⃣ 矩阵乘法 - 信息的变换

### 💡 日常类比
想象你是一个**食谱转换器**：
- 你有一个配方（输入向量）：`[2个鸡蛋, 100克面粉, 50克糖]`
- 你有一套转换规则（权重矩阵）：把配方转换成营养成分
- 输出：`[蛋白质克数, 碳水化合物克数, 热量]`

**矩阵乘法 = 应用一套转换规则**

### 🔢 数学理解
```
输入向量：     x = [x₁, x₂, x₃]
权重矩阵：     W = [[w₁₁, w₁₂, w₁₃],
                    [w₂₁, w₂₂, w₂₃]]
输出：         y = W @ x = [y₁, y₂]

其中：
y₁ = w₁₁*x₁ + w₁₂*x₂ + w₁₃*x₃
y₂ = w₂₁*x₁ + w₂₂*x₂ + w₂₃*x₃
```

### 📊 在Transformer中的应用
**神经网络的每一层都在做矩阵乘法 = 学习如何变换信息**
- 输入 `[batch, seq_len, d_model]`
- 权重 `[d_model, d_output]`
- 输出 `[batch, seq_len, d_output]`

## 3️⃣ 词嵌入 (Embedding) - 词语的数字化表示

### 💡 日常类比
想象你要向计算机描述"狗"和"猫"：
- ❌ 不能直接用文字："dog", "cat"（计算机不理解）
- ✅ 用特征向量：
  - 狗：`[体型:中, 忠诚度:高, 独立性:低, 会叫:是]` → `[0.5, 0.9, 0.3, 1.0]`
  - 猫：`[体型:小, 忠诚度:中, 独立性:高, 会叫:否]` → `[0.3, 0.5, 0.8, 0.0]`

**相似的词在向量空间中距离更近！**

### 🔢 数学理解
```
词汇表大小：vocab_size = 10000
嵌入维度：  embedding_dim = 512

嵌入矩阵：  E = [vocab_size, embedding_dim]
           = [10000, 512]

查询词 "hello" (索引 = 42):
word_vector = E[42]  # 取出第42行，得到512维向量
```

### 📊 在Transformer中的应用
```
输入句子（token索引）：[5, 42, 189, 7]
           ↓ 查表（embedding lookup）
词向量矩阵：[[0.1, 0.5, ...],  # 第5个词的512维向量
            [0.3, 0.2, ...],  # 第42个词的512维向量
            [0.8, 0.1, ...],  # 第189个词的512维向量
            [0.2, 0.9, ...]]  # 第7个词的512维向量
形状：[4, 512]  # 4个词，每个512维
```

## 4️⃣ 注意力机制 (Attention) - Transformer的核心创新 ⭐

### 💡 日常类比 - "阅读理解中的注意力"

假设你在读这个句子：**"The animal didn't cross the street because it was too tired."**

问题：**"it" 指的是什么？**

你的大脑会：
1. 🔍 看到 "it"，触发"需要找指代对象"
2. 👀 回看前面的词：
   - "street" - 不太可能，街道不会累
   - **"animal" - 很可能！动物会累** ⭐⭐⭐⭐⭐
   - "cross" - 不是名词
3. 🎯 结论："it" = "animal"，注意力集中在这个词上

**这就是注意力机制！当前词（it）去"查询"其他词，找到最相关的信息（animal）。**

### 🔢 数学直觉（先别怕公式！）

注意力的三个角色：
```
Query (查询者)：   "我是'it'，我想知道我指代谁？"
Key (被查询者)：   每个词都说："我是'animal'，我有这些特征..."
Value (信息内容)： "如果你关注我，我能提供这些信息..."
```

**注意力得分 = Query 和 Key 的匹配度**

```
步骤：
1. 计算相似度：  score = Query · Key^T  （点积）
2. 归一化权重：  attention_weight = softmax(score)
3. 加权求和：    output = attention_weight · Value
```

### 📊 具体例子（简化版）

句子："cat sat mat"（猫坐在垫子上）

```
当处理词 "sat" 时：
Query("sat") 与每个词的 Key 计算相似度：
  - Key("cat"):  0.8  (高！主语)
  - Key("sat"):  0.3  (中等，自己)
  - Key("mat"):  0.6  (较高，地点)

Softmax 归一化 → [0.5, 0.1, 0.4]

加权组合各词的 Value：
output = 0.5 * Value("cat") + 0.1 * Value("sat") + 0.4 * Value("mat")
       = "sat" 的新表示，融合了主语和地点信息！
```

**关键洞察**：注意力让每个词都能"看到"其他词，并选择性地融合相关信息！
