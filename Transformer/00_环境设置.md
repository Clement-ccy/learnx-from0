# 环境设置指南

## 📋 所需依赖

本项目需要以下Python库：
- **PyTorch** - 深度学习框架（核心）
- **NumPy** - 数值计算
- **Matplotlib** - 可视化（后续用于绘制注意力图）

## 🚀 安装步骤

### 方法1：使用pip安装（推荐）

```bash
# 安装PyTorch (CPU版本，适合学习)
pip install torch torchvision torchaudio

# 如果你有NVIDIA GPU，可以安装GPU版本（更快）
# pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

# 安装其他依赖
pip install numpy matplotlib
```

### 方法2：使用conda安装

```bash
# 创建新环境
conda create -n transformer python=3.11

# 激活环境
conda activate transformer

# 安装PyTorch
conda install pytorch==2.3.0 torchvision==0.18.0 torchaudio==2.3.0 pytorch-cuda=12.1 -c pytorch -c nvidia

# 安装其他依赖
conda install -c pytorch torchtext==0.18.0 spacy portalocker torchdata

# 下载数据集（此处用的是PowerShell）
spacy download en_core_web_sm | python -m spacy download de_core_news_sm
```

## ✅ 验证安装

运行以下命令验证安装：

```bash
python -c "import torch; print(f'PyTorch版本: {torch.__version__}')"
python -c "import torch; print(f'CUDA可用: {torch.cuda.is_available()}')"
```
